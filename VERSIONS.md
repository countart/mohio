| 4.8.1 | 2026-08-05 | 2030-08-05 | AGPL-3.0-or-later | v4.8.1 | Patch release. Fixes a packaging gap where the installed wheel shipped with no grammar file at all (`mohio.lark`, the sector profiles, and the langmaps relocated into `mohio_data/` so they are actually included); `connect db as sqlite from env.X` now consults its declared source instead of silently falling back to the constructor default; `miosearch`'s check-time severity corrected from WARNING to ERROR to match its real runtime crash. Also includes the durable session-store provider seam (in-memory and Postgres-backed session storage, survives a process restart, preserves role and hold-scoped state), which landed on `main` between `v4.8` and this tag and lives inside `mohio_interpreter.py`, already part of the Licensed Work. | 4.8.2 | 2026-08-08 | 2030-08-08 | AGPL-3.0-or-later | v4.8.2 | Patch release, security and data-integrity focused. `modify ... where` with a two-part condition now filters to the matching rows instead of silently changing every row. An app that declares no database no longer crash-loops when the host sets a `DATABASE_URL`, and `mio audit verify` now opens Postgres and MySQL rather than only local files. A page with no address set now answers only at the home path instead of at every URL, closing an unauthenticated-write surface (both the ordinary and the crafted-request routes). A failed step inside a `transaction` now rolls the whole block back instead of leaving a partial write committed. A misspelled or unknown field access now fails loud with a suggestion instead of silently returning nothing, and `random.token`/`random.number` used without their required details refuse clearly rather than yielding nothing. Searching a plain in-memory list with `find`/`retrieve`/`grab` now gives a clear message instead of failing silently (full support for querying held sources is tracked separately). A mixed `and`/`or` condition is now a check-time error rather than being silently grouped, matching the browser-side rule. Release hygiene: the version is defined in one place with a guard preventing the two version files from disagreeing, the incorrect license label is removed from every shipped file, the project-wide license reference now points at the real `LICENSE` file, login and safety libraries ship in a plain install, and the source distribution is published alongside the wheel. File scope for this version is fixed by the `LICENSE-SCOPE.md` committed at the tag above. |
