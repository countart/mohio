# Mohio Manual -- Getting Started

Getting started now has one home: **`Docs/manual/mohio-manual-part1-ch1-hello-mohio.md`** (Part I,
Chapter 1). Read that first. It covers everything this file did and adds the install steps and the one
shift a reader from another language needs.

This file was a second walkthrough of the same ground, and two documents covering the same ground drift
apart, so it was retired to a pointer rather than maintained alongside the chapter. What it uniquely
carried moved INTO Chapter 1: the comparison-word list, the `unless` one-liner, and the short "Numbers,
casts, and booleans" section. Nothing was lost; there is now one place to keep correct.

Read next, in order, once Chapter 1 is done:

- **Chapter 2** -- a small app with real data: `Docs/manual/mohio-manual-part1-ch2-small-app-real-data.md`
- **Chapter 6** -- values and output: `Docs/manual/mohio-manual-part2-ch6-variables-and-output.md`
- **Chapter 8** -- working with text: `Docs/manual/mohio-manual-part2-ch8-working-with-text.md`
- **Chapter 11** -- decisions: `Docs/manual/mohio-manual-part3-ch11-decisions.md`
- **Chapter 12** -- loops: `Docs/manual/mohio-manual-part3-ch12-loops.md`

Whenever you are unsure whether something is a mistake, run `mio check yourfile.mho`. It reads your
program without running it and points at the exact line, usually with a fix.
